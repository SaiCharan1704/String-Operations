# String Operations

## Objective
Implement string manipulation programs in Java.

## Features
- Check if a string is a palindrome
- Count the number of vowels in a string

## Concepts Used
- Strings
- Loops
- Conditional Statements
- Character Manipulation
- Scanner Class

## Technologies Used
- Java
- Eclipse IDE

## Sample Output

Input: madam
The string is a Palindrome.
Number of vowels: 2
